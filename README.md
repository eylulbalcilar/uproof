# uproof

Corroboration-based proof of field work for humanitarian programs.

Anyone can submit a proof. Anyone can corroborate it. Trust comes from how many
independent people report the same event, not from who they are.

Built at FIRSTBLOCK-ATHON 2026, UNICEF problem statement.

## Structure

- `contracts/` Solidity contracts, Foundry, Base Sepolia
- `app/` Vite + React + TypeScript frontend
- `server/` Express proxy for photo checks and identity verification
